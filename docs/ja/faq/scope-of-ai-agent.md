# 本サイトのスコープ

範囲の定義は [序章](../preface) が持つ。ここには、よく検索される問いへの短い案内だけを置く。

本書が扱う AI は、主に LLM（大規模言語モデル）である。Claude のような対話システムの中身がこれに当たる。強化学習や、昔の規則ベースは扱わない。中心が LLM ではない構成は、対象にしない。

Skills / MCP / Memory / Doctrine は、そのモデルが最初から持っている限界への答えとして置く。範囲、扱わないもの、読者は序章 0.2 から 0.4 を見る。
