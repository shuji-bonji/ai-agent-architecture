# Scope of this book

The definition of scope belongs to the [Preface](../preface). This page is only a short pointer for a common search query.

The AI this book treats is primarily an LLM (large language model). That is the core of conversational systems such as Claude. Reinforcement learning and classical rule bases are out of scope. Designs whose core is not an LLM are not the subject here.

Skills, MCP, Memory, and Doctrine are placed as answers to limits the model already has. For scope, exclusions, and readers, see Preface sections 0.2 to 0.4.
